# m.code — Matteo Scandola

Portfolio of **Matteo Scandola (m.code)**, visual artist, researcher and VJ based in Paris.
Real-time audiovisual installations and live visuals made with TouchDesigner.

**Live site: https://skandiz.github.io/mcode-portfolio/**

Selected works: Messico e Nuvole (Komorebi 2026), States of Motion (MART, Rovereto), Proximity, Nails / Landlord, Inwards, bette2rave and live VJ sets.
